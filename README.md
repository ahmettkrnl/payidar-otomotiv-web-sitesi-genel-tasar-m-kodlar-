# Payidar Otomotiv | Özel Servis Web Sitesi

Payidar Otomotiv için geliştirdiğim, mobil uyumlu bir özel servis web sitesi projesidir.

Bu projedeki amacım, araç sahiplerinin servis hizmetleri hakkında kolayca bilgi alabilmesini ve araçlarının sorunlarını servise gitmeden önce hızlıca iletebilmesini sağlamaktı.

Sadece işletmeyi tanıtan bir web sitesi yerine, müşterilerle servis arasındaki iletişimi kolaylaştıran bir sistem oluşturmaya odaklandım.

## Canlı Web Sitesi

**[Payidar Otomotiv Web Sitesini Ziyaret Et](https://payidarotomotivozelservis.gt.tc/)**

## Projenin Özellikleri

- **Responsive Tasarım:** Telefon, tablet ve bilgisayarlara uyumlu arayüz.
- **Dijital Servis Asistanı:** Araç sahiplerinin servis taleplerini adım adım oluşturabilmesi.
- **WhatsApp Entegrasyonu:** Müşterinin verdiği bilgileri düzenli bir WhatsApp mesajına dönüştürme.
- **Usta Seçimi:** Selim Usta veya Serkan Usta'ya doğrudan yönlendirme. Tercih belirtilmediğinde rastgele yönlendirme.
- **Araç Marka Bilgileri:** Farklı otomobil markalarını tanıtan bölüm.
- **Kampanyalar:** Arıza tespiti ve periyodik bakım kampanyaları hakkında bilgi alma.
- **Mobil Video:** Masaüstü ve mobil cihazlar için optimize edilmiş giriş animasyonu.
- **Modern Arayüz:** Koyu tema, altın renk detayları ve sade navigasyon.

## Payidar ile Hızlı İletişim

Projede özellikle üzerinde durduğum bölüm, dijital servis talep sistemidir.

Kullanıcı bu sistemde araç markası, modeli, motor bilgileri, vites tipi, kilometre ve yaşadığı sorun gibi bilgileri doldurabilir. İhtiyaç duyduğu hizmeti ve iletişime geçmek istediği ustayı seçebilir.

Form tamamlandığında bilgiler JavaScript kullanılarak tek bir mesaj hâline getirilir. Kullanıcı WhatsApp'a yönlendirilir ve mesajını göndererek servis talebini iletebilir.

Bu sistemin amacı, müşterinin aynı bilgileri tekrar tekrar anlatmasını azaltmak ve servis personelinin talebi daha düzenli değerlendirebilmesini sağlamaktır.

| HTML5 | Sayfa yapısı ve formlar |

## Projeyi Yerel Ortamda Çalıştırma

1. GitHub deposunu bilgisayarınıza indirin.
2. Proje klasörünü açın.
3. `index.html` dosyasını tarayıcıda çalıştırın.

Alternatif olarak Visual Studio Code üzerinden Live Server kullanabilirsiniz.
